========================================
5. ISSUES & POTENTIAL IMPROVEMENTS
========================================

5.1 Issues Ditemukan:

A. Struktur HTML tidak konsisten di indexabad (lines 115-126)
   - setelah tab "Anak" berakhir, ada div closing/opening yang tidak sepenuhnya
   - terlihat seperti KPR tab content berada di dalam struktur yang salah
   - Mungkin menyebabkan tab KPR tidak menampilkan konten dengan benar atau
     menimbulkan layout break di browser

B. File gambar logo dengan spasi di nama
   - "logo gki.png" memiliki spasi
   - Meskipun bekerja di Windows, bisa menjadi masalah pada server web
   - Direkomendasikan mengganti underscore atau hyphen: "logo_gki.png"

C. Missing accessibility attributes
   - Beberapa tombol dan link kurang memiliki aria-label yang deskriptif
   - Formulir doa tidak memiliki label yang ter-associated dengan input

D. Konsistensi warna pada halaman publik
   - --warna-biru-doa (#3f51b5) hanya digunakan di section doa dan profil
   - Pada halaman utama (index.html), warna biru tidak digunakan secara signifikan
   - Skema warna utama: cokelat (brown), emas (gold), cream (cream)
   - Disarankan untuk memperluas penggunaan warna biru secara meragam jika diinginkan

E. Potensi konflik namespace antara app.js dan admin.js
   - Keduanya mendefinisikan var dengan nama serupa (KEY_WARTA, KEY_JADWAL, dll)
   - Jika keduanya ter-load di satu halaman, ada risiko definisi ganda
   - Namun karena admin.html tidak termasuk di index.html (dan sebaliknya), belum
     menjadi masalah nyata

5.2 Suggestions for Improvements:

A. Perbaiki struktur HTML di index.html
   - Pastikan setiap tab (raya, anak, kpr) memiliki pembukaan dan penutup div yang
     sepenuhnya seimbang
   - Validasi HTML melalui validator W3C

B. Ekstrak warna biru ke penggunaan yang lebih luas
   - Gunakan --warna-biru-doa untuk warna link, hover state, atau elemen CTA lainnya
   - Buat variasi warna (--warna-biru-terang, --warna-biru-gelap) jika butuh gradient

C. Perbaikan responsive pada tab jadwal
   - Di mobile, tab-buttons sudah full width (sudah oke)
   - Pastikan schedule-card tetap menarik di layar kecil
   - Test tombol tab active state di touch device

D. Optimasi performa localStorage
   - Data yang terlalu besar di localStorage bisa memengaruhi performa
   - Pertimbangkan limit ukuran data atau clean-up rutin

E. Tambah fallback untuk missing localStorage
   - Pastikan semua bacaData selalu memiliki fallback yang tepat
   - Validasi tipe data sebelum di-parse JSON

F. Tingkatkan accessibility di admin panel
   - Tambah aria-label pada input PIN
   - Tambah fokus visible pada elemen yang dapat di-focus
   - Validasi panjang PIN sebelum submit
